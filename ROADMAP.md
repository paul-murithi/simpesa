# Future Enhancements

Sim-Pesa has achieved its primary goal. The following are potential future directions for the project:

- **B2C, C2B, B2B Integration**: Mocking full money transfer cycles.
- **Account Balance & Transaction Queries**: Complete Daraja API coverage.
- **Chaos Mode**: Simulating network failures and edge-case error codes.
- **Multi-Merchant Dashboard**: Support for managing multiple test environments.

See the [Future Enhancements Guide](docs-site/docs/guide/future-enhancements.md) for more details.
